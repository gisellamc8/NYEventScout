# NYEventScout

Created by Gisella Castillo and Dereck Marquez

**Description**:
Ask about someone's career, then find the fairs, conferences and events that fit
This notebook turns the Food Analyzer lab into a career-event matching app. The app:

asks what the user is looking for — networking, job hunting, internships, learning new skills, exploring a career, mentorship, or a career change;
asks for their job title or major, and their year in college if they are a student;
ranks career fairs, conferences, networking nights, workshops and info sessions to fit, with a % match and plain-language reasons on every card;
uses your LM Studio chat model to write a short personalized plan (top picks, prep tips, an elevator pitch), and links to live searches for real upcoming events (Google, Eventbrite, Meetup, LinkedIn, and Handshake for students).
The layout follows the reference design: purple hero banner, a search bar with borough and price filters, category chips, event cards with Save buttons, and a "Your career agent" sidebar with a Saved events list.
